# LIMO ROS Navigation Code

ROS Noetic source for the AgileX LIMO patrol and navigation work.

- [Portfolio case study and technical report](https://scandial-portfolio.scandium.chatgpt.site/project-limo.html)
- [Public case-study companion](https://github.com/scandium1102/limo-autonomous-navigation)
- [ROS package organization draft](https://github.com/scandium1102/all-limo-control/pull/5)

The case study covers a broader graduation project, including mapping, localization and the natural-language destination pipeline. This repository is the ROS navigation code companion. The linked draft organizes the ROS package and describes its launch files and checks. The reported experiments were performed in Gazebo.
